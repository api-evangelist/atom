# Atom (atomchat.io)

> Atom is a Panama-based conversational-commerce platform (ATOMCHAT, S.A., Panama City) whose multimodal AI Agents combine text, voice, image and CRM data to run human-like WhatsApp conversations that qualify leads and close sales across Latin America. Founded in 2019 by Erick Holmann and Rene Mouynes and backed by Techstars and Mucker Capital. Atom is an official WhatsApp Business Solution Provider. It exposes two documented REST APIs — a Customers API and a WhatsApp Templates API — both served from Google Cloud Functions at https://us-central1-atomchat-io.cloudfunctions.net and authenticated with a static account bearer token issued from the Atom admin panel. Atom publishes no OpenAPI, no AsyncAPI, no MCP server and no agent card.

## APIs
- [Atom Customers API](https://soporte.atomchat.io/knowledge/api-de-clientes): Create or update a customer, list all customers, get a customer by ID. Base: https://us-central1-atomchat-io.cloudfunctions.net
- [Atom WhatsApp Templates API](https://soporte.atomchat.io/knowledge/como-enviar-templates-messages-utilizando-la-api-de-atomchat): Send pre-approved WhatsApp template messages via POST /api/Template/SendMessage (templateId, phoneNumber, clientName, groupName, assign, params); list templates via /templates.

## Authentication
- Bearer token: `Authorization: Bearer <public token>`, plus `Content-type: application/json` and `Charset: utf-8`. The token is a static account API token generated in the Atom admin panel under Configuracion > Mi Empresa > Configuraciones (security settings), and the same token authenticates webhook-triggered flows.
- No OAuth 2, no OpenID Connect, no scopes, no documented token expiry or rotation. All four /.well-known auth-discovery paths return 404.

## What Atom does NOT publish
- No OpenAPI/Swagger document on any host (probed /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs, /docs, /redoc).
- No GraphQL endpoint, no AsyncAPI document, no gRPC/protobuf.
- No MCP server (mcp.atomchat.io does not resolve) and no A2A agent card.
- No client SDK in npm, PyPI, RubyGems, crates.io, Packagist, NuGet or Maven Central.
- No published API rate limits, no status page, no deprecation policy, no API changelog, no idempotency contract.
